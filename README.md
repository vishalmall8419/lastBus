# 🌙 About The Project

**LAST BUS** is an immersive cinematic web experience inspired by the feeling of travelling on a late-night Indian bus.

Imagine sitting beside a window late at night.

The road is almost empty.

Rain is falling on the window.

Highway lights pass by.

The city slowly disappears behind you.

Music is playing through the radio.

The clock keeps moving.

And the journey continues.

**LAST BUS** attempts to recreate that feeling inside a browser.

Instead of building another conventional website, this project focuses on creating an **interactive digital journey** where visuals, time, music and atmosphere work together.

# 🚀 Getting Started

Follow these steps to run LAST BUS locally.

## 📋 Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git
- YouTube Data API v3 access

---

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/vishalmall8419/lastBus.git
```

---

## 2️⃣ Open the Project

```bash
cd lastBus
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

# 🔐 Environment Configuration

Create a `.env` file in the root directory.

```env
VITE_YOUTUBE_API_KEY=YOUR_YOUTUBE_API_KEY
```

Replace:

```text
YOUR_YOUTUBE_API_KEY
```

with your YouTube Data API v3 key.

---

# ⚠️ API Key Security

Do **not** upload your `.env` file to GitHub.

Your `.gitignore` should include:

```text
.env
.env.local
.env.*.local
```

For production deployment, configure the API key through your hosting platform.

It is also recommended to restrict your API key through Google Cloud Console using:

- HTTP referrer restrictions
- YouTube Data API v3 restriction
- Appropriate quota controls

---

Start the development server:
